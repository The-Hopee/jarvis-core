# Как проверить Джарвиса

Для разговора, документов и облачной речи см. [обновление 0.4](docs/UPGRADE_04.md).
Telegram/VK подключаются пользователем отдельно. OpenRouter проверен с отдельным
inference key; лимит текущего ключа $5 без периодического сброса. Подбор конечного
голоса продолжается по результатам прослушивания.

## 1. Проверить запуск

Откройте PowerShell:

```powershell
cd C:\Users\tima\jarvis-core
.\manage.cmd status
```

Ожидается `Jarvis-HomeAssistant Running` и `"running": true`. Фоновый помощник
уже запущен; выходить из Windows или перезагружаться для первой проверки не нужно.

## 2. Проверить голос и базовые инструменты

Произнесите по одной команде, дожидаясь окончания ответа:

1. «Джарвис, состояние машины» — услышите реальные показатели компьютера.
2. «Джарвис, открой ютуб» — браузер получит команду открытия YouTube.
3. «Джарвис, открой телеграмм» — запустится зарегистрированный Telegram.
4. «Джарвис, какая погода?» — погода для города из `JARVIS_CITY`.

Затем проверьте разговор и документы:

1. «Джарвис, открой вс код» — запуск VS Code и уместный вопрос о работе.
2. Ответьте «да, новый проект» без повторения имени в течение 40 секунд.
3. «Создай документ с текстом: Список дел на сегодня» — DOCX в Documents\Jarvis
   и запрос открытия в ONLYOFFICE. Оригинальные документы не перезаписываются.
4. После выбора видео — «включи второе», без повторного поиска и перестановки результатов.
5. «Отбой» — помощник снова ждёт имя. «Джарвис, я дома» — новая беседа.

«Сверни все окна» и «сделай тише» меняют рабочий стол/звук — проверяйте их в удобный
момент. Тесты не выполняют эти действия на ваших текущих окнах.

Для просмотра распознанной фразы и ответа используйте:

```powershell
.\manage.cmd logs
```

Чтобы видеть результат сразу в терминале:

```powershell
.\manage.cmd foreground
```

Эта команда останавливает фоновый экземпляр и включает голосовой режим в
консоли. Завершение — Ctrl+C, затем `manage.cmd start` для возврата в фон.

## 3. Проверить OpenRouter отдельно

На этом ПК ключ уже настроен. После самостоятельной замены ключа в `.env`:

```powershell
.\manage.cmd restart
.\run.cmd -Text
```

В текстовом режиме попросите: `Ответь одним словом: связь установлена?`.
Это запрос к модели; простой обработчик локальных команд на такой вопрос не отвечает.
Для выхода из текстового режима введите `/exit`.

При `HTTP 401` OpenRouter не принимает ключ: проверьте, что ключ создан в
OpenRouter как обычный inference key, скопирован целиком и не отозван. Management
key годится для управления ключами, но не для completions. Модель и путь к Telegram не исправят
ошибку авторизации. После замены ключа снова выполните `manage.cmd restart`.
`HTTP 402` означает проблему с балансом, `429` — ограничение запросов.

Фоновый голосовой процесс можно оставить работающим при короткой текстовой
проверке; не произносите голосовые команды одновременно с ней.

## 4. Если микрофон не слышит

```powershell
.\.venv\Scripts\python.exe -m jarvis --list-mics
```

Укажите выбранный номер как `JARVIS_MICROPHONE` в `.env`, затем перезапустите
помощника. Для отдельной проверки динамиков:

```powershell
.\.venv\Scripts\python.exe -m jarvis --speak "Проверка голоса"
```

Текущий TTS/ASR можно посмотреть через `--doctor`. При сбое облачного TTS сначала
используется локальный мужской Silero, затем Windows. Микрофонные записи на диск
не сохраняются. Для ASR OpenRouter отправляется только активированная реплика.

## 5. Проверить автозапуск

При следующем обычном входе в Windows подождите около 10 секунд и произнесите
«Джарвис, состояние машины». Автозапуск также виден в Планировщике заданий под
именем `Jarvis-HomeAssistant`. Проверка настоящего события входа не требует
принудительного выхода из системы во время настройки.

Остановка на текущий сеанс: `manage.cmd stop`. Запуск: `manage.cmd start`.
Остановка не отключает автозапуск при следующем входе.
