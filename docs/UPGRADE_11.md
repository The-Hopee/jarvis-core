# Версия 0.11 RC — готовый Windows пакет

Jarvis.exe и JarvisPanel.exe содержат Python runtime, C++ ядро, Vosk-модель,
кодеки и зависимости обычного облачного/Windows профиля. PyInstaller 6.22.3
собирает их в одну папку. NVIDIA и компилятор на целевом ПК не требуются.
Дополнительный браузер Chromium скачивается из панели, только если нужен VK.
Личная Silero/Torch-установка разработчика не включается в базовый пакет.

Панель: скрытый ввод ключа, город, микрофон, выбор ASR/TTS, собственный образец
голоса, диагностика, проверка речи, запуск/остановка, подключения, автозапуск,
обновление из распакованного нового пакета, откат и удаление. Обновления сохраняют
личные настройки и сессии в отдельном каталоге. Удаление личных данных — отдельный
явный выбор. Незавершённая копия пакета очищается только внутри проверенного
каталога staging данной версии. Установщик проверяет состав файлов и SHA256.
Это контроль целостности, пакет пока не имеет подписи издателя.

packaging/build_release.py создаёт ZIP, manifest и SHA256. Состав задаётся явно;
.env, agent.py, сессии, журналы, переписка и образцы владельца не копируются.
Внутри есть русское HTML-руководство и лист испытания. Workflow windows-release.yml
собирает и проверяет пакеты на Windows runner по тегам; публикация предварительная.

Проверки установки/обновления/отката, повреждения и лишних файлов находятся в
tests/test_distribution.py. Дополнительная команда готового EXE --self-test
проверяет native IPC/метрики, Vosk, DOCX, MP3 decoder, morphology, зависимости
браузера и UI без сети и озвучивания. Она не отправляет сообщения.

Чистый профиль на текущей Windows не равен новой машине. Фактический вход в
Windows, характеристики компьютера дяди и самостоятельный пилот остаются
внешними проверками. Telegram отложен по просьбе владельца. Поэтому стабильный
тег 1.0 не ставится до выполнения листа пилота.

Пакет включает manifest с activeCodePage=UTF-8: без него Vosk из готового EXE
не открывал файлы модели в пути с кириллицей. Это настройка процесса, системная
локаль Windows не меняется. Основание:
https://learn.microsoft.com/en-us/windows/apps/design/globalizing/use-utf8-code-page

Дополнительно по просьбе владельца введён модуль приватности: локальная диктовка,
защита private turn/history/background/TTS, блок облачного контекста переписки,
ZDR-маршруты текстовых моделей и ограничение сетевых назначений браузера VK.
Проверка --privacy-check без реальных аккаунтов и сети. Подробности: PRIVACY.md.
Планы кодящих задач могут быть больше четырёх; число работающих процессов
согласуется с CPU/RAM и общим бюджетом. Подробности: AGENT_ARCHITECTURE.md.
Реальный межпроцессный тест выявил ошибку кодировки stdin браузерного процесса:
ввод теперь явно UTF-8, русские команды не обрывают протокол.
