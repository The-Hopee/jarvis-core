# Музыка VK

Скилл работает через отдельную вкладку в сохранённом браузерном профиле Джарвиса.
Переписка открывается в другой вкладке; чтение диалога не перезагружает проигрыватель.
Голос и OpenRouter-модель из настроек остаются прежними.

## Один раз войти

Из `C:\Users\tima\jarvis-core`:

```powershell
.\manage.cmd stop
.\.venv\Scripts\python.exe -m jarvis --vk-login
.\manage.cmd start
```

Войти нужно самостоятельно в открывшемся окне VK, затем нажать Enter в консоли.
Пароль/код остаются в локальном браузере. После ответа «нужен вход» фоновый браузер
закрывается и освобождает профиль, чтобы эта команда не упиралась в его блокировку.

## Команды

- «Джарвис, включи трек Розовое вино в VK».
- «Джарвис, найди песню [исполнитель и название] во ВКонтакте» — показать до пяти результатов.
- После поиска: «включи вторую песню» — выбрать из полученного списка без повторного поиска.
- «Джарвис, поставь музыку на паузу».
- «Продолжи музыку» — пока действует окно разговора после паузы.
- «Джарвис, следующий трек» / «предыдущий трек».
- «Джарвис, что сейчас играет в VK?».
- «Джарвис, сделай тише» — уменьшить громкость Windows на 10 пунктов.

Во время воспроизведения следующую команду произносите с «Джарвис», чтобы текст
песни не воспринимался как продолжение беседы. После подтверждённой паузы обычное
окно разговора возвращается. Отдельное обращение по имени всё ещё даёт короткое
время на следующую команду.

## Что проверяет скилл

Инструменты: `search_vk_music`, `play_vk_music`, `play_vk_music_result`,
`control_vk_music` (`pause`, `resume`, `next`, `previous`, `status`). Громкость
регулируется существующими инструментами Windows.

Результаты берутся из видимых строк треков. Перед нажатием сверяются название,
исполнитель и идентификатор строки: при перестановке результатов другой трек
не запускается. Выбор по номеру помнит сервис: треки VK и видео YouTube не смешиваются.
Новая тема музыки также сбрасывает отложенный выбор собеседника, чтобы номер трека
не стал случайным продолжением старой просьбы отправить сообщение.

Успешное нажатие кнопки само по себе не означает воспроизведение. Подтверждение
проверяет отмеченную строку и продвижение времени HTML audio, включая плееры с
отдельным `new Audio()` вне DOM. В облачную модель возвращаются название, исполнитель
и статус; ссылки на аудиопоток, cookies и токены не передаются. Если подтверждения
нет, результат — `play_requested`, `playback_verified=false`, `do_not_retry=true`.
Повтор одного действия в текущем обращении использует сохранённый результат,
чтобы не выключить уже запущенный трек вторым нажатием или не пропустить два трека.

Пауза не переключает проигрывание обратно. Новый поиск сохраняет текущий трек;
продолжение использует общий проигрыватель, даже если прежнего трека нет в результатах.
При закрытии/перезапуске Джарвиса закрывается принадлежащий ему браузер и музыка в нём.
Доступность треков определяется обычным доступом аккаунта VK; скилл не скачивает музыку
и не выполняет действия подписки.

## Проверка

Автоматические проверки используют настоящий Chromium и локальные страницы с
реальным WAV в отсоединённом HTML Audio. Проверяются поиск, запуск и время,
пауза/продолжение, следующий/предыдущий трек, перестановка результатов,
зависший проигрыватель, повторные действия, разделение вкладок, вход и маршрутизация
голосовых команд. Тестовая WAV содержит тишину и не воспроизводит чужую музыку.

Реальный запрос через браузерный IPC дошёл до страницы входа VK и вернул
`vk_login_required`. Вход ранее отложен пользователем. Авторизованный интерфейс и
настоящие треки этого аккаунта ещё не проверены. При отличающемся интерфейсе VK
понадобится уточнить селекторы по странице после входа; скилл сообщает ошибку,
а не придумывает найденный трек или успешный запуск.

YouTube-скилл уже существует: «Джарвис, открой на ютубе видео Егора Крида».
Он находит реальный watch URL; «включи второе видео» выбирает предыдущий результат.

Технические источники:
[Playwright locators](https://playwright.dev/python/docs/api/class-locator),
[HTMLMediaElement.paused](https://developer.mozilla.org/en-US/docs/Web/API/HTMLMediaElement/paused).
