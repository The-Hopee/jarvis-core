Jarvis для Windows x64. Распакуйте ZIP целиком, откройте JarvisPanel.exe и нажмите
«Установить / обновить». Python и сборка C++ на компьютере пользователя не нужны.
Внутри есть русское руководство и лист самостоятельной проверки.

Нужны собственный OpenRouter API-ключ с балансом, микрофон, динамики и интернет.
Базовый голос Windows работает без NVIDIA. VK использует отдельный браузерный
профиль; Chromium скачивается кнопкой «Браузер VK».

Проверены: модельные профили и tools, фоновые задачи, кодящий мастер с двумя
исполнителями и тестами/ревью, DOCX, VK музыка и запись самому себе без дубля.
Telegram отложен из-за блокировки создания приложения у владельца.

По выбору владельца переписка не отправляется облачным ИИ, ASR локальное.
Голос A остаётся для обычных ответов; приватный текст озвучивается локально.
Ответ по контексту «в моём стиле» отключён до подключения локальной модели.
Панель содержит проверку защиты с вымышленными данными, без доступа к аккаунтам.
Пул кодящих исполнителей допускает планы больше четырёх задач и учитывает CPU/RAM.

Пакет остаётся предварительным: ещё нужны самостоятельная установка и проверка
после входа в Windows на другом ПК, а также проверка обычных адресатов VK и Telegram.
Наличие тегов следующих этапов не означает, что эти внешние проверки пройдены.

Перед запуском проверьте SHA256. Пакет не подписан сертификатом издателя.
Сессии, ключи, переписки и личный голос владельца в архив не включены.
