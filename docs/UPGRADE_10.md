# Версия 0.10 — проверенный кодящий режим

Настоящий GPT-6 Sol high через OpenRouter выполнил демонстрационную задачу:
мастер спланировал две независимые работы, два процесса-исполнителя реализовали
slugify.py и отдельные unittest, изменения объединены в отдельном worktree,
проверки прошли и независимое ревью одобрило результат. Стоимость по usage.cost
составила 0.0484112 USD при локальном лимите 1 USD.

Статус: ready_for_review. Исходный checkout и его HEAD не изменились.
Демонстрационный проект зарегистрирован как jarvis-demo; он отдельный от проектов
владельца. Результат расположен в локальном coding-jobs, путь выдаёт status.
Ничего не объединялось с main и не отправлялось во внешние проекты.

Команда: «В проекте jarvis-demo реализуй …». Модель должна назвать зарегистрированный
project_id; если проект не выбран, помощник уточняет его. Проверки задаются
владельцем локально как argv-массивы. Доступен --checks-file для JSON без сложного
экранирования аргументов терминала. План, исполнители, тесты и ревью отражаются
в состоянии задачи. При отмене останавливаются только дочерние процессы задачи;
worktree и результат сохраняются для разбора.

Windows-процессы получили общий помощник запуска для исходников и готового EXE.
Владение помощником привязано к каталогу личных данных, чтобы обновление версии
не запускало второго слушателя микрофона. JARVIS_DATA_DIR позволяет изолированные
проверки пакета без ключей и сессий основного профиля.

Ограничения: проверки и worktree не являются песочницей ОС. Для реального проекта
нужны Git, его зависимости и доверенные команды тестов. Автоматического принятия
изменений, push, merge и деплоя кодящий режим не выполняет.
