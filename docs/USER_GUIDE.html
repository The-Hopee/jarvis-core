Домашний Джарвис

Помощник для Windows x64. Пакет содержит Python, C++ ядро и локальное распознавание речи. Устанавливать Python, Visual Studio или CMake для обычных функций не нужно. NVIDIA не требуется. Для облачного разговора нужны интернет, собственный ключ OpenRouter и баланс.

Это предварительный выпуск для домашнего испытания. Самостоятельная установка на компьютере другого человека и Telegram ещё ожидают проверки. Стабильный выпуск 1.0 будет после пилота.

Установка за несколько шагов

  1. Получите ZIP и файл .sha256 из Releases репозитория Jarvis либо от владельца. Репозиторий пока закрытый: без доступа можно воспользоваться переданным архивом.
  2. Распакуйте ZIP целиком. Рядом с JarvisPanel.exe должны остаться Jarvis.exe, папка _internal и manifest.json. Не запускайте EXE прямо из ZIP.
  3. Откройте JarvisPanel.exe и нажмите «Установить / обновить». Права администратора не нужны. Программа проверяет состав файлов и создаёт ярлыки.
  4. Введите ключ OpenRouter в скрытом поле и свой город. Нажмите «Микрофоны» и при необходимости укажите номер устройства. Распознавание оставьте vosk, озвучивание для начала — windows.
  5. Нажмите «Сохранить настройки», «Диагностика», «Проверить защиту данных» и «Проверить голос». Затем «Запустить» и скажите: «Джарвис, состояние машины».

Программа устанавливается в %LOCALAPPDATA%\Programs\Jarvis\versions. Ключ, авторизации, очередь и журналы хранятся отдельно в %LOCALAPPDATA%\Jarvis. Не передавайте папку личных данных другим людям; в установочный ZIP она не входит.

Пакет не подписан сертификатом издателя. Windows может показать SmartScreen. Проверьте происхождение архива и SHA256; хеш подтверждает целостность, а не личность издателя. Не отключайте защиту Windows.

Приватность

Переписка VK/TG не передаётся облачным ИИ. Диктовка распознаётся локально. Голос A можно использовать для обычных ответов; содержимое переписки озвучивается локально через Windows. «Ответь по контексту в моём стиле» отключено до подключения локальной модели.

Обычные вопросы, документы и код, порученные облачному ИИ, могут передаваться OpenRouter и провайдеру модели. Для текстовых моделей запрашиваются ZDR и запрет сбора данных. Это не превращает помощника в полностью офлайн-программу. VK и Telegram получают данные, необходимые для работы самих платформ.

«Проверить защиту данных» запускает проверки с вымышленными сообщениями и подставными транспортами. Реальные аккаунты не открываются; данные в сеть не отправляются. Счётчики аудита содержат только категории и решения, без переписки, аудио и ключей. Это проверка путей Jarvis, а не монитор всего сетевого трафика Windows. Подробности — в файле ПРИВАТНОСТЬ.md.

Голос и стоимость

Для важной диктовки сначала скажите «Режим переписки» и дождитесь подтверждения. После команды чата он также включается автоматически: непонятая следующая фраза останется локальной. Для выхода скажите «Заверши переписку». Это защищает от ошибок распознавания намерения в продолжении диалога.

Локальный Vosk включён для защиты диктовки. Проверяйте распознавание имён и сообщения сначала на «Избранном». Для обычной речи доступен Windows, Edge либо OpenRouter. Для OpenRouter Fish Audio выберите свой WAV-образец и впишите точный текст записи; либо останьтесь на Windows/Edge. Чистая запись даёт более естественный результат. Личный голосовой архив владельца не включён в пакет.

Для личного голоса короткие статусы можно подготовить без воспроизведения: Jarvis.exe --prepare-status-voice. Для базового Windows голоса они создаются при сохранении настроек. Потоковое аудио и короткие статусы уменьшают время ожидания, но скорость облачных моделей зависит от сети и провайдера.

Поставьте общий предел расходов у своего API-ключа OpenRouter. Локальные лимиты текстовых моделей: $0.10 на лёгкую реплику, $0.30 на документную, $1 на кодящую задачу. Это консервативный учёт по ценам на 05.11.2026, не гарантия счёта провайдера. Облачный голос оплачивается отдельно. Локальное распознавание не тарифицируется сервисом.

Режимы моделей

Выбранный образец облачного голоса тоже передаётся TTS-сервису. Используйте запись без личных сведений. Диктовка команд при этом распознаётся локально.

  • «Включи авто»: обычные команды — GPT-4.1 mini, документы — GPT-6.1 Terra low, код и явно сложные рассуждения — GPT-6 Sol high.
  • «Включи лёгкий / документный / кодящий режим»: ручной выбор профиля.
  • «Какой режим?» и «Включи авто»: узнать выбор и вернуться к автоматике.

Выбор по словам может ошибаться. Для долгой задачи используйте «в фоне». Только подходящие инструменты подключаются под текущую задачу. В режиме JARVIS_PRIVACY_MODE=offline_ai облачные LLM/ASR/TTS запрещены; свободный диалог требует локальной модели, которой в этой версии ещё нет.

VK и Telegram

Для VK нажмите «Браузер VK», дождитесь установки Chromium, затем «Войти в VK». Пароль вводите только в открывшемся браузере. После входа нажмите Enter в окне подключения. Примеры: «Включи трек … в ВК», «Пауза в ВК», «Открой диалог с … в ВК», «Напиши … в ВК: …».

При совпадении имён помощник уточняет адресата. Некоторые изменения интерфейса могут потребовать обновления. После неподтверждённой отправки сначала проверьте диалог, чтобы не повторить сообщение. В браузере Jarvis разрешены нужные домены VK/CDN и блокируются посторонние HTTP/WebSocket назначения; новый вход с ограничениями ещё нужно проверить на другом ПК.

Для Telegram создайте собственное приложение на my.telegram.org, затем нажмите «Войти в Telegram». api_id, api_hash, код и пароль вводятся локально. Это личный аккаунт через API, не Bot API. Если сайт пишет Too many attempts, отложите подключение — остальные функции доступны. Живая проверка Telegram в этом выпуске отложена. Начинайте с собственного «Избранного».

Кодящий режим

Для него дополнительно нужны Git и инструменты самого проекта. Зарегистрируйте локальный Git-репозиторий из терминала в папке программы:

Jarvis.exe --internal coding register demo C:\Projects\demo --checks-file checks-python.json

Файл-пример входит в пакет и предполагает установленный Python с доступной командой python. Для другого проекта задайте свои доверенные argv-команды проверок. Скажите: «В проекте demo реализуй …».

Один мастер заранее строит план минимум для двух заданий исполнителям, с зависимостями и назначенными файлами. План может быть больше четырёх задач; одновременно работает ограниченный пул по CPU и свободной RAM. Следующие задачи ждут, законченные процессы заменяются новыми. После объединения отдельно проходят реальные проверки и ревью. Общий бюджет делят все роли. Подробности есть в AGENT_ARCHITECTURE.md репозитория.

Результат сохраняется в отдельной Git-ветке для вашего просмотра. Автоматического merge/push/deploy нет. Проверки кода работают с правами пользователя; worktree не является песочницей ОС. Для недоверенного репозитория используйте отдельную ОС-песочницу.

Автозапуск, обновление и удаление

После установки отметьте «Запускать после входа в Windows». Это запуск в вашем сеансе, где доступны микрофон и приложения. Для обновления распакуйте новый архив, откройте его JarvisPanel и нажмите «Установить / обновить». Помощник сначала завершает текущую работу. Личные данные сохраняются; предыдущая версия остаётся для кнопки «Откат версии».

«Удалить программу» удаляет только управляемый каталог программы и ярлыки. Настройки и сессии сохраняются, пока вы отдельно не отметите их удаление. Откат не отменяет ранее отправленные сообщения и изменения документов.

Если что-то не работает

  • Нет звука: проверьте выход Windows и «Проверить голос». Временно выберите Windows. Для облачного голоса проверьте ключ, баланс и образец.
  • Не слышит: разрешите микрофон для классических приложений Windows и выберите устройство. Убедитесь, что Jarvis запущен. Для проверки используйте короткие фразы.
  • HTTP 401/402/403 или нет ZDR-маршрута: проверьте ключ, баланс и доступность модели. Политика приватности автоматически не ослабляется.
  • Уже работает: «Остановить», дождитесь завершения, затем «Запустить». Второй экземпляр не запускается.
  • Документ создался, но не открылся: установите ONLYOFFICE либо откройте DOCX вручную из Documents\Jarvis.
  • VK требует вход: остановите помощника и повторите «Войти в VK». Не выключайте защиту данных для обхода ошибки; сообщите версию и обезличенный текст ошибки.
  • Долго думает: лёгкий режим, короткие запросы или фон. Команда Jarvis.exe --latency-report --latency-source voice показывает измерения без текста.

«Журнал» открывает личные логи. assistant.log может содержать ваши фразы: удаляйте личные данные перед передачей. Никому не передавайте ключи, коды, сессии, папку браузера и личные образцы. Для пилота заполните «ПРОВЕРКА-УСТАНОВКИ.md».
