# Приватные команды и локальный голос

Модуль доступен в main после ZIP 0.11.0-rc.1. Он уже установлен на рабочем ПК
владельца; опубликованный ZIP RC1 остаётся прежним. Языковая модель составляет
текст и разбирает команды, отдельная TTS-модель превращает текст в голос.

Используются Qwen3.5-4B Q4_K_M через llama.cpp CUDA и Qwen3-TTS 0.6B Base.
Файл текстовых весов — 2.74 GB; голосовые веса с токенизатором — около 2.51 GB.
CUDA/Python и зависимости занимают дополнительное место. Веса, окружение,
эталон голоса и профиль стиля находятся в `%LOCALAPPDATA%\Jarvis`, вне Git.

## Как говорить

- «Джарвис, режим переписки» / «Включи приватный режим».
- «Напиши в ВК Ивану Иванову сообщение Привет, буду через десять минут».
- «Напиши Ивану сообщение Привет»: помощник уточнит мессенджер и сохранит текст.
- «Напиши Ивану в ВК»: помощник спросит текст сообщения.
- «Подготовь черновик ответа Ивану в ВК в моём стиле», затем «Отправь».
- «Ответь Ивану в ВК в моём стиле»: разрешает составить и отправить ответ.
- «Отмена»: отменить собираемое сообщение.
- «Выход из приватного режима», «Закрой приватный режим», «Заверши переписку»:
  закрыть процессы моделей и очистить приватный контекст перед обычным диалогом.

При разборе без явной границы имени и текста модель предлагает получателя и
сообщение для подтверждения. Буквальный текст копируется из диктовки; предложенный
моделью пересказ не отправляется. При совпадении имён остаётся выбор адресата.
После неподтверждённой доставки сначала проверьте диалог, чтобы избежать дубля.

## Как подстраивается стиль

Откройте нужный диалог и скажите «Запомни мой стиль в этом диалоге».
Сохраняются только исходящие примеры выбранного собеседника, до 60 сообщений.
Дальнейшие явно продиктованные отправки дополняют включённый профиль. Ответы,
сгенерированные самим помощником, не используются для обучения на самом себе.

Профиль хранится в `private/style.json`, отдельно для VK и Telegram и каждого
собеседника. Поле `rules` позволяет задать общие предпочтения. При подготовке
ответа локальная модель получает профиль и ограниченный контекст выбранного
диалога. Это персонализация по примерам, без изменения весов модели. Она не
означает, что программа узнала все факты о владельце. Черновики нужно оценить
на своём общении; при недостатке фактов модель должна уточнять их.

## Процессы, скорость и приватность

Процессы запускаются по необходимости и завершаются после 90 секунд простоя.
Таймер выгрузки освобождает ресурсы, сохраняя защиту следующей диктовки. Для
возвращения к облачному диалогу используется явная команда выхода. Приватные
слоты, черновики и история не переносятся облачной модели.

В проверке обе модели с рабочим столом занимали около 7.3 GiB VRAM, после выгрузки
занято около 1.5 GiB. Первый разбор команды с загрузкой модели занял около 3 s,
разбор и генерация короткого черновика на прогретой модели — около 1.2 s. Это
синтетические команды с подставными аккаунтами, без времени браузера и микрофона.

Первый синтез выбранного локального голоса занял около 16 s, повторный — около
7 s на короткую реплику. Восемь постоянных реплик подготовлены заранее и играют
локально, без повторной загрузки модели. Произвольный новый текст по-прежнему
требует синтеза. Для CUDA используется BF16: FP16 приводил к ошибкам вычислений.

В модели не передаются облачные ключи через окружение. LLM слушает только loopback
с временным ключом; голосовой процесс общается по stdin/stdout, работает с локальными
файлами и блокирует сетевые подключения. Win32 Job Object закрывает собственные
дочерние процессы и при аварийном завершении родителя. Это не изоляция всего ПК
или недоверенного кодящего проекта; подробности в [PRIVACY.md](PRIVACY.md).

## Повторная установка из исходников

Нужна NVIDIA CUDA GPU с BF16 (проверено на RTX 3060) и достаточно места для весов
и отдельного Python-окружения. Установка рассчитана на Python 3.13 x64.
Обычный помощник и базовый Windows-голос могут работать без NVIDIA.

```powershell
.\setup-local-ai.ps1
.\.venv\Scripts\python.exe scripts\setup_private_models.py --verify-only
```

Установка фиксирует ревизии и SHA256, не меняет основное Python-окружение.
После установки создайте `%LOCALAPPDATA%\Jarvis\local-ai.json`:

```json
{
  "enabled": true,
  "voice_enabled": true,
  "idle_seconds": 90,
  "voice_reference": "C:/path/to/local-reference.wav",
  "voice_reference_text": "Точный текст записи"
}
```

Этот образец используется только локальным синтезатором; публичный облачный
голос сохраняет свои отдельные настройки. Для стандартных реплик выполните
`python scripts/prepare_private_voice.py`, затем `manage.cmd restart`.
`JARVIS_LOCAL_AI=0` и `JARVIS_LOCAL_VOICE=0` отключают соответствующие возможности;
в этом случае приватная озвучка остаётся локальной через Windows.

Проверки без настоящих аккаунтов: `scripts/local_ai_smoke.py`,
`scripts/local_voice_smoke.py --target-a`, `scripts/local_lifecycle_smoke.py`.
Последний проверяет оба процесса, выгрузку и сетевую границу. Telegram требует
отдельного входа; его живая проверка по просьбе владельца пока отложена.

Первичные источники: [языковая модель](https://huggingface.co/Qwen/Qwen3.5-4B),
[GGUF](https://huggingface.co/unsloth/Qwen3.5-4B-GGUF),
[голос](https://huggingface.co/Qwen/Qwen3-TTS-12Hz-0.6B-Base),
[llama.cpp](https://github.com/ggml-org/llama.cpp/tree/master/tools/server).
