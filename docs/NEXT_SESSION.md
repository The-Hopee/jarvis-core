## Какой помощник нужен

- Голосовой ориентир — Джарвис Тони Старка из фильмов с русской киноозвучкой.
  Пользователь хочет узнаваемые тембр и манеру, а не просто произвольный низкий
  мужской голос. Сейчас выбран локальный Silero Eugene; это временный вариант,
  а не достигнутое совпадение с голосом из фильма. Подбор проверять прослушиванием.
- Помощник должен вести живую беседу, учитывать контекст и уместно продолжать
  разговор. Пример пользователя: на «Открой VS Code» выполнить действие и спросить
  «Мы работаем над новым проектом?». Не превращать беседу в повторные запросы
  разрешения на уже понятные команды; уточнять действительно недостающие сведения.
- Платные модели распознавания речи разрешены для улучшения точности русского
  голосового ввода. Конкретный провайдер и модель ещё не выбраны. Не путать
  транскрибацию с переводом на другой язык. В этот день новые платные вызовы
  ради подбора не запрошены.

## Приоритет разработки

Сначала довести повседневного интерактивного помощника:

1. Открытие приложений, включая VS Code.
2. Работа с документами и заполнение документов в ONLYOFFICE.
3. Личные сообщения Telegram и VK: выбор правильного собеседника, продиктованный
   текст, чтение выбранного контекста и ответ в стиле владельца по его просьбе.
4. Поиск и открытие конкретных нужных видео.
5. Затем расширять остальные возможности.

План мастера, субагентов, отдельных Git worktree, проверок и ревью ранее утверждён.
Первый контур уже реализован, но его дальнейшее расширение следует текущему
приоритету бытовых функций. Все новые возможности проверять эмпирически.
