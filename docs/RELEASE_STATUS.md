Стабильный 1.0 не выпущен: установка на компьютере дяди, вход в Windows с
автозапуском, характеристики его машины и отложенные подключения требуют
его/владельца участия. Это не препятствует передаче предварительного ZIP для пилота.

История проверок: VALIDATION.md и docs/benchmarks. Время синтетических повторов
не выдаётся за задержку живого микрофона в комнате. ASR/TTS оплачиваются отдельно
от локальных лимитов текстовых моделей. Жёсткий предел ключа OpenRouter не менялся.

Последнее решение владельца: ASR теперь Vosk локально, переписка закрыта от
облачных ИИ. Голос A сохранён для обычных ответов, приватный текст озвучивается
локально. Ответ по стилю требует ещё не подключённой локальной модели.
Снято ограничение четырёх задач: очередь планов и допуск процессов по CPU/RAM.
Защита проверяется вымышленными canary-данными и браузерным тестом блокировки.

Независимый CI: [успешный прогон f90aa0d](https://github.com/The-Hopee/jarvis-core/actions/runs/42089775592).
В main включён C++20 для нового MSVC; исправлены две переносимые проверки
путей/каталога отчёта. Публичные файлы релиза не заменялись. Успешный CI не
подменяет самостоятельный интерактивный пилот дяди.
