# Версия 0.9 RC — бытовые функции

Живой тест VK с существующей авторизацией подтвердил поиск, включение конкретного
трека и паузу. Звук в проверочном браузере был выключен; проверяется движение
HTML audio и точное название в плеере, не акустический выход. Исправлен случай,
когда современный VK убирает включённый трек из поисковой выдачи.

Добавлены современные элементы VK Messenger и специальное открытие собственного
«Избранного». Проверочная запись отправлена только самому владельцу, сохранение
подтверждено после перезагрузки страницы. Повтор той же операции вернул квитанцию,
вторая запись не отправлялась. Браузерные тесты воспроизводят этот случай.
Для современных элементов локальный оптимистический пузырь не считается отправкой:
сообщение должно сохраниться после reload. Неподтверждённые отправки не повторяются.

Telegram поддерживает алиасы «Избранное» / Saved Messages / me для будущей проверки.
Пользователь отложил живую проверку Telegram: my.telegram.org ещё блокирует
создание приложения. Внешним людям тестовые сообщения не отправлялись.
Обычные адресаты VK требуют отдельной проверки на выбранном владельцем диалоге.
Поэтому 0.9 имеет статус RC; полный критерий приёмки сообщений ещё не закрыт.

Сборка ядра использует статическую MSVC runtime, чтобы не требовать Visual Studio
или отдельной установки runtime для самого C++ ядра. Версия native и Python согласована.
